# React Modal

## Problem Statement

Build a modal component.

## Requirements

- [x] Opening a modal shows the contents of the modal
- [x] Open modals are on top of a scrim
- [x] Open modals prevent the underlying screen from being scrolled
- [x] Can be closed by clicking off the modal
- [x] Escape key closes the modal
- [x] When open, no tab stops are focused that are not within the modal
