# React Tabs

## Problem Statement

Create a tab component. The problem is purposefully nebulous and you must decide what interactions it should contain.

## Requirements

- [x] Only one tab panel is visible at a time
- [x] Activating a tab will display its corresponding tab panel
- [x] Tabs can be navigated via left/right keyboard interactions
- [x] Tab navigation stops at the first/last tab when continuing to navigate via keyboard interactions
- [x] Mousing over a tab will set it as the currently active tab
- [x] Enter/space will activate the currently active tab
- [x] Tabbing from a focused tab will move the focus to the corresponding tab panel, then into the first tab stop within the tab panel
- [x] Tabbing through a tab panel will not stop at tab stops in panels that are not currently activated
